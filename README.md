# Baldin' Ring

A browser-playable parody boss fight. Street Fighter-style 1v1 against Evil Bald, who spams the group chat into oblivion.

## Play

Open `index.html` in any modern browser. Or play the hosted version (if deployed).

## Controls

- **A / D** - walk (back direction = block)
- **W / SPACE** - jump
- **S** - crouch
- **J** - light attack
- **K** - heavy attack
- **L** - character special (3 charges)
- **H** - drink healing flask

## Characters

- **Ladder Man** - lanky goon, swings a literal ladder
- **Generic White** - knight, sword + shield + counter
- **Slug** - throws UFC tickets like Gambit

## Boss

**Evil Bald** has 7 distinct attacks. Phase 2 kicks in at 50% HP - "BACK ONLINE."

## Built with

HTML5 Canvas + plain JavaScript. SNES-style pixel sprites generated via Nano Banana (Gemini 2.5 Flash Image). Tech house boss theme generated via ElevenLabs Music API.
